# 生成プロンプトの雛形

**正本は [`build-posts.py`](build-posts.py) の `PROMPT` 定数。** このファイルは読んで確認するためのもので、
実際に使うときは下のコマンドで出力し、そのままコピーして Web版 Claude に貼る。

```shell
python3 instagram/build-posts.py --prompt brand-ritz     --count 4 --start 2026-09-01
python3 instagram/build-posts.py --prompt next-platinum  --count 2
python3 instagram/build-posts.py --prompt iroishi-market --count 2
```

`accounts.json` を書き換えれば、プロンプトに埋め込まれる前提条件（トーン・取扱品目・投稿の型・
ハッシュタグ・法定表記・NG表現・CTA）も自動で追従する。**雛形と台帳を二重管理しないこと。**

雛形そのものを直したいときは `build-posts.py` の `PROMPT` を編集し、
このファイルの実行例も同じコマンドで貼り直す。
